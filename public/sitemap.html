서비스

폼 만들기개인정보 보호형 폼을 만들고 공유합니다.사용 가이드폼 만들기, 응답 운영, 암호화 키 관리와 개인정보 수집 운영을 확인합니다.브랜드 리소스공식 로고, 심볼, 색상, 사용 원칙을 확인합니다.브랜드 사용 가이드형식·해상도 선택과 공식 표기·사용 원칙을 이 사이트에서 확인합니다.보안과 응답 암호화응답이 암호화되어 저장되는 방식을 확인합니다.자주 묻는 질문키 관리, 응답 운영, 개인정보 고지의 기본을 확인합니다.

정책

개인정보처리방침콕폼 플랫폼 처리와 폼 운영자 책임을 확인합니다.개인정보 국외이전 안내국내 저장 구조와 조건부 해외 처리 가능성을 확인합니다.서비스 이용제한 정책금지행위, 비례적 조치, 이의제기 기준을 안내합니다.이용약관서비스 이용과 운영 기준을 안내합니다.검색엔진용 XML 사이트맵검색엔진과 자동화 도구가 사용하는 URL 목록입니다.
검색엔진용 XML 사이트맵: 크롤러와 자동화 도구는 /sitemap.xml을 사용합니다. 이 페이지는 사람이 필요한 안내와 정책 문서에 빠르게 도착할 수 있도록 만든 공개 사이트맵입니다.
