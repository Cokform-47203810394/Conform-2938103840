응답 암호화

응답 원문은 작성자만 읽도록 설계했습니다.

응답은 제출자의 브라우저에서 암호화되어 저장됩니다. 폼 작성자는 자신의 브라우저에 있는 키로만 응답을 열고 내보낼 수 있습니다.

알아두세요: 암호화가 모든 위험을 없애지는 않습니다. 작성자는 기기·브라우저·복구 비밀번호·내보낸 파일을 직접 안전하게 관리해야 하며, 키를 백업하지 않은 상태에서 브라우저 저장 데이터를 삭제하면 기존 응답을 복구할 수 없습니다.

응답 원문이 저장되는 방식

  1. 응답자가 공개 링크에서 답을 입력합니다.
  2. 답은 제출자의 브라우저에서 폼별 공개키를 이용해 암호화됩니다.
  3. 저장소에는 암호화된 응답 데이터와 제출 시각이 저장됩니다.
  4. 폼 작성자는 자신의 브라우저 개인키로 응답을 열고 CSV·Excel 파일로 내보냅니다.

콕폼이 처리하는 것과 읽지 못하는 것

콕폼은 로그인 식별 정보, 폼 구조와 운영 설정, 암호화된 응답, 최소 운영 통계를 처리할 수 있습니다. 정상적인 암호화 응답 원문은 콕폼 운영자나 저장소 제공자가 복호화 키 없이 읽을 수 없도록 설계했습니다.

조회 통계는 폼별 조회·응답 건수만 다루며, 응답 원문과 분리합니다. 자세한 기준은 개인정보처리방침에서 확인하세요.

작성자가 해야 할 일

민감한 개인정보는 최소한으로 수집하고, 목적·항목·보관기간·동의 거부권을 폼에서 고지하세요. 개인정보를 수집한다면 콕폼의 개인정보 안내와 동의 질문을 실제 운영 내용에 맞게 설정해야 합니다.
