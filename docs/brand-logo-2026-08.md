# Cokform Logo Refresh · 2026-08

Cokform의 새 로고는 **정돈된 체크리스트와 완료 표시**를 결합한 초록 심볼이다. 복잡한 폼 화면을 그대로 묘사한 생성 시안은 작은 헤더·파비콘 크기에서 과도하게 상세하고 가장자리 색 번짐이 있어, 제품 로고로는 사용하지 않았다.

생산용 단독 마크는 딥 포레스트 그린 `#0F5B46`, 신뢰감 있는 그린 `#17866D`, 민트 `#EAF7EF`, 아이보리 `#FFFDF8`만 사용한다. 두 개의 응답 행과 하단의 체크 원은 “명확하게 묻고, 안전하게 답을 모은다”는 의미를 전달한다. 단순한 벡터 구조이므로 헤더, 편집기 아이콘, 작은 화면에서도 명료하게 유지된다.

워드마크는 한글 `콕폼`과 작은 영문 보조 문구 `FORM, CLEARLY`로 구성한다. 초록 계열은 기존 브랜드의 연속성을 유지하면서, 형광 라임·말풍선 중심의 이전 인상보다 더 차분하고 신뢰도 높은 업무용 톤을 만든다.
