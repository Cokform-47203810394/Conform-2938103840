# 콕폼 법적 문서 패키지 초안

> **법률 검토 전 초안입니다.** 실제 공개 전 운영자 정보, 요금제, 환불 기준, 지원 범위, 데이터 처리업체 계약, 한국 법률 검토를 반영해야 합니다.

## 1. 서비스 이용약관 초안

### 제1조 목적
본 약관은 콕폼이 제공하는 온라인 폼 작성·공유·응답 관리 서비스의 이용 조건과 이용자와 콕폼 사이의 권리·의무를 정하는 것을 목적으로 합니다.

### 제2조 서비스의 성격
콕폼은 이용자가 폼을 작성하고 응답을 수집할 수 있는 기술적 도구를 제공합니다. 콕폼은 이용자가 폼에 입력하도록 정한 개인정보의 수집 목적, 법적 근거, 고지 적정성, 응답 내용의 정확성에 관한 책임을 부담하지 않으며, 이용자는 자신이 운영하는 폼의 개인정보처리 책임과 관계 법령 준수 의무를 부담합니다.

### 제3조 계정과 소유권
작성자는 본인의 Google 계정으로 폼 소유권을 확인합니다. 작성자는 계정 접근 정보를 보호해야 하며, 계정 침해가 의심되면 즉시 문의해야 합니다. 작성자가 만든 폼의 질문·설명·브랜드 콘텐츠에 대한 권리는 관련 법령상 작성자 또는 정당한 권리자에게 귀속됩니다.

### 제4조 금지행위
이용자는 불법 정보, 타인의 권리를 침해하는 정보, 악성코드, 사기·피싱·스팸, 차별·협박·성착취·불법 촬영물, 법령상 수집이 제한된 고위험 개인정보를 콕폼을 통해 수집하거나 배포해서는 안 됩니다. 콕폼은 긴급한 보안·법적 사유가 있는 경우 접근 제한 또는 삭제를 할 수 있습니다.

### 제5조 암호화와 한계
콕폼은 응답 원문을 작성자 브라우저에서 암호화하는 기술을 사용하지만, 이용자 기기의 악성코드, 브라우저 확장프로그램, 계정 탈취, 작성자가 직접 내보낸 파일, 공동 작업자 권한 오남용까지 방지하지는 않습니다. 작성자는 복호화 키와 내보내기 파일을 안전하게 관리해야 합니다.

### 제6조 서비스 변경과 중단
보안 패치, 법령 준수, 장애 복구, 인프라 변경을 위해 서비스 일부가 변경·중단될 수 있습니다. 합리적으로 예측 가능한 중단은 사전 공지하고, 긴급한 보안 조치는 사후 공지할 수 있습니다.

### 제7조 책임 제한
콕폼은 고의 또는 중대한 과실이 없는 한 이용자의 폼 운영, 응답자가 제공한 정보, 이용자의 법적 고지 누락으로 발생한 손해에 대해 책임을 부담하지 않습니다. 다만 이 조항은 관계 법령상 제한할 수 없는 책임을 제한하지 않습니다.

### 제8조 준거법과 문의
본 약관은 대한민국 법률을 준거법으로 하며, 분쟁은 관계 법령에 따른 관할 법원에서 해결합니다. 사업자·주소·문의처는 공개 전 실제 정보를 기재합니다.

## 2. 폼 운영자 법적 체크리스트

| 확인 | 운영자가 확인할 내용 |
|---|---|
| 목적 | 왜 필요한 정보인지 한 문장으로 설명할 수 있는가 |
| 최소수집 | 목적 달성에 필요하지 않은 주민번호·건강정보·민감정보를 제거했는가 |
| 고지 | 수집 항목·목적·보유기간·동의 거부권을 제출 전에 보여주는가 |
| 동의 | 선택 동의와 필수 동의를 구분하고 거부 시 불이익을 설명했는가 |
| 아동 | 만 14세 미만 대상 여부와 법정대리인 절차를 확인했는가 |
| 제공 | 제3자 제공 대상·목적·항목·기간을 별도로 고지했는가 |
| 위탁 | Supabase·Cloudflare·메일 발송 등 처리위탁과 국외 이전을 확인했는가 |
| 보관 | 목적 달성 후 삭제일과 책임자를 정했는가 |
| 권리 | 열람·정정·삭제·처리정지 요청을 받을 연락처가 있는가 |
| 접근 | 공동 작업자와 다운로드 파일의 접근 권한을 최소화했는가 |
| 사고 | 유출·오발송·계정 탈취 시 신고·통지 절차를 정했는가 |

## 3. 공개 전 확정해야 할 서비스 정보

현재 문서의 대괄호 항목은 공개 전 반드시 채워야 합니다. 대표자 또는 법인명, 사업자등록번호, 사업장 주소, 개인정보 보호책임자, 권리행사 이메일, 서비스 이용약관 시행일, 실제 Supabase·Cloudflare·Google·메일 서비스의 처리지역과 재위탁 정보, 유료화 시 결제·환불 기준이 이에 포함됩니다.
