# 한국형 유입 채널·제품 관찰 메모

**확인일:** 2026-08-20

## 현재 제품 관찰

- 홈은 `빈 양식`, `내 폼 사본`, 템플릿 캐러셀, 내 폼, 참여한 양식으로 구성되어 있다.
- 템플릿은 상담·문의, 예약, 교육·행사 참가, 출결, 견적, 채용, 만족도, 개인정보 동의, 단체 주문 등을 제공한다.
- 편집기는 공유 시작·흐름·답변·운영 탭과 제목, 테마, 미리보기, 실행취소/재실행, 버전, 링크, 공동작업자 제어를 상단에 동시에 둔다.
- 편집기에는 우측 빠른 질문 유형 추가와 문항별 축소/선택 상세 편집이 있다.
- 제품의 강점은 한국어 업무 템플릿, 폼 구조의 자유도, 브라우저 기반 E2EE 방향이다.
- 제품의 약점은 첫 핵심 고객군과 결과 중심 메시지가 넓고, 편집기 상단 조작 밀도가 높으며, 승인·마감·후속 처리 같은 수직 업무 완료 흐름이 아직 핵심 제품으로 묶이지 않은 점이다.

## 인용용 사실

- 카카오톡 채널 공식 페이지는 웹사이트 방문 등 행동 유도 버튼, 1:1 채팅, 자동응답, 친구 수·메시지 클릭 등 통계를 설명한다.
- 카카오 알림톡은 API 기반 정보성 메시지이며 공식 딜러사를 통해 제공된다고 안내한다.
- 당근 비즈프로필 공식 페이지는 2026년 1월 기준 비즈프로필 170만+, 단골 980만+를 제시한다.
- 네이버 스마트플레이스는 업체등록, 예약/주문 메뉴를 제공한다.

## 전략 원칙

1. Discord는 커뮤니티 운영자 파일럿 채널이지 브랜드의 유일한 유입 기반이 아니다.
2. 카카오는 응대·공지, 네이버는 검색·발견, 당근은 지역 기반 파일럿, 자체 콘텐츠는 장기 자산으로 역할을 분리한다.
3. 콕폼은 대형 예약 플랫폼과 정면 경쟁하지 않고, 기존 도구가 약한 자유 질문·동의·승인·마감·내보내기 흐름을 해결한다.
4. 광고보다 10개의 실제 운영 사례와 전환 데이터가 우선이다.
