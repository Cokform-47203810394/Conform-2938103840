# 개인정보 국외이전 및 국외 처리 안내

> **법률 검토 전 공개 초안**입니다. 이 문서는 2026-08-18 기준 Cokform의 코드·배포 구성을 바탕으로 작성했습니다. 실제 사업자 정보, Cloudflare 계약·데이터 현지화 설정, Google 연동 범위, 처리자 연락처·보유기간이 변경되면 시행 전 반드시 갱신해야 합니다.

Cokform은 응답 내용을 제출자 브라우저에서 암호화하고, 작성자가 자신의 개인키로 읽도록 설계합니다. 그러나 암호화 여부와 별개로 계정 식별자, 접속 기술정보, 암호문 응답, 폼 구조 등 개인정보 또는 개인정보와 결합될 수 있는 정보가 처리 인프라·선택 연동을 통해 국내외에서 처리될 수 있으므로 이 안내를 제공합니다.

## 1. 기본 원칙

Cokform은 국외 처리·이전이 필요한 기능을 최소화하고, 외부 연동은 사용자가 직접 선택하거나 실제 서비스 제공에 필요한 범위에서만 사용합니다. 국외이전의 법적 근거, 처리자, 국가, 처리 항목, 보유기간, 거부 방법과 효과는 개인정보처리방침과 이 문서에 함께 공개합니다.

> 국외이전은 개인정보가 해외의 제3자에게 제공·처리위탁·보관되거나 해외에서 조회되는 경우에 성립할 수 있습니다. 해외 사업자가 이용자로부터 직접 수집하는 경우와 Cokform이 해외 처리자에게 이전하는 경우는 구분해 검토합니다.[1][2]

## 2. 현재 국내 저장 구조

Cokform의 Supabase 프로젝트는 `ap-northeast-2`(대한민국 서울) 리전에 구성되어 있습니다. 폼 구조, 운영 설정, 작성자 인증 관련 데이터, 암호화된 응답 envelope, 응답 메타데이터, 참여 이력 등은 이 리전의 서비스 구성에서 처리·보관되도록 설정되어 있습니다.

응답 평문은 제출자 브라우저에서 폼별 공개키로 암호화되어 전송되고, 복호화는 작성자의 브라우저에서 개인키 금고를 연 경우에 수행됩니다. 이 특성은 응답 원문의 접근 범위를 줄이기 위한 기술적 설계이며, 다른 개인정보 처리·고지 의무를 대체하지 않습니다.

## 3. 국외 처리 또는 이전 가능성이 있는 기능

| 구분 | 처리자 또는 서비스 | 처리될 수 있는 항목 | 국가·지역 | 시기·방법 | 목적·보유 | 거부 방법과 효과 |
|---|---|---|---|---|---|---|
| 웹 전송·보안 | Cloudflare, Inc. 및 관련 처리자 | IP 주소, 브라우저·기기·접속 기술정보, HTTP 요청 메타데이터, 정적 웹 자산 요청 | 전 세계 네트워크. 미국 등 해외 처리 가능성이 있음 | 웹사이트 접속 시 HTTPS·엣지 네트워크 처리 | 웹페이지 전송, 보안, 안정성·오류 대응. 정확한 로그 보유기간은 Cloudflare 서비스·계정 설정에 따름 | 웹 서비스 접속을 중단할 수 있으나, 접속 자체에 필요한 전송·보안 처리는 거부 시 이용이 제한될 수 있음 |
| 선택 내보내기 | Google LLC / Google Drive | 사용자가 선택한 복호화 내보내기 파일과 파일명·형식 등 업로드 메타데이터 | Google이 고지하는 국가·지역. 해외 처리 가능성 있음 | 사용자가 Google Drive 또는 Sheets 내보내기를 실행하고 Google 권한을 허용할 때, 브라우저에서 Google API로 직접 전송 | 사용자가 선택한 Drive·Sheets 파일 생성. 보유기간은 사용자의 Google 계정·설정과 Google 정책에 따름 | Google 연동 권한을 허용하지 않거나 내보내기를 실행하지 않으면 됨. 이 경우 Google Drive·Sheets 직접 내보내기를 쓸 수 없음 |

Cloudflare는 전 세계 네트워크에서 트래픽을 처리하며, 별도 데이터 현지화 기능으로 암호 해제·로그·메타데이터의 처리 위치를 제어할 수 있는 기능을 제공합니다.[3] Cokform은 무료 파일럿 구성에서 이 기능의 적용 여부와 계약 조건을 지속적으로 점검하며, 처리 위치 제한이 필요한 고객에게는 적용 가능 여부를 별도로 안내합니다.

Google Drive·Sheets 내보내기는 사용자의 명시적 실행과 Google 권한 동의가 있을 때만 동작합니다. Cokform은 `drive.file` 범위를 사용해 사용자가 선택한 파일 생성 범위에만 접근하도록 구현했으며, Drive 전체 파일 접근 권한을 요청하지 않습니다.

## 4. 국외이전의 법적 근거와 고지

Cokform은 실제 국외 이전이 발생하는 처리자별로 개인정보 보호법 제28조의8 등 관계 법령이 요구하는 적법한 근거를 확인하고 공개합니다. 법률상 별도 동의가 필요한 이전은 해당 동의를 별도로 받으며, 계약 이행을 위한 처리위탁·보관 등 다른 근거를 사용하는 경우에는 해당 근거와 법정 고지사항을 개인정보처리방침에 명확히 공개합니다.[1][2]

| 공개·검토 항목 | Cokform 운영 기준 |
|---|---|
| 이전 항목 | 기능에 실제 필요한 항목만 목록화하고, 응답 원문·암호문·접속정보를 구분 |
| 국가·시기·방법 | 서비스별 실제 처리 지역과 네트워크·API 전송 방식을 갱신 |
| 이전받는 자 | 법인명, 문의 경로, 처리위탁 또는 직접 연동의 구분을 공개 |
| 이용 목적·보유기간 | 서비스 제공·보안·사용자 선택 내보내기 등 목적별로 분리 |
| 거부권 | 선택 연동은 미사용 가능. 접속 필수 인프라는 거부 시 서비스 이용 제한 가능성을 명시 |

## 5. 보호조치

Cokform은 다음과 같은 조치를 적용하거나 운영 기준으로 유지합니다.

- HTTPS 전송 보호와 Supabase 행 수준 접근제어를 적용합니다.
- 응답 원문은 제출자 브라우저에서 암호화하고, 작성자의 개인키 금고 없이 정상적으로 읽을 수 없도록 설계합니다.
- 내보내기 파일은 작성자의 브라우저에서 생성되므로, 사용자는 다운로드·Drive 전송 전에 필요한 정보만 포함됐는지 확인해야 합니다.
- 외부 처리자의 개인정보 보호 문서, 하위 처리자, 데이터 현지화·보관 설정을 주기적으로 점검합니다.
- 침해 사고·권리 요청·분쟁이 발생하면 관계 법령과 계약상 절차에 따라 대응합니다.
