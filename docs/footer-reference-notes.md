# 참고 푸터 레이아웃 관찰 메모

## 타일 1–2: 좌측 영역

참고 화면은 검은 배경과 매우 얇은 상단 구분선으로 시작한다. 콘텐츠는 넓은 최대 폭 안에서 3열로 배치되어 있으며, 좌측 열은 브랜드의 신뢰 영역이다.

- 원형 심볼과 굵은 영문 브랜드명이 한 줄에 배치된다.
- 브랜드 아래에는 서비스 정체성을 한두 문장으로 설명하는 짧은 문장이 있다.
- 그 아래에는 GitHub 아이콘과 `FIGMA`, `EMAIL` 같은 외부 연락·프로필 링크가 작은 캡스 스타일로 놓인다.
- 상단 정보 영역과 하단 고지 영역 사이에는 넓은 여백이 있고, 가로선으로 구분된다.
- 가로선 아래에는 펼침/접힘 가능한 `오픈소스 라이선스` 고지가 있다.
- 마지막 영역에는 연도·권리 문구와 더 작은 저작권/상표 고지가 배치된다.

Cokform 적용 원칙: 좌측은 `COKFORM` 브랜드·E2EE 요약·GitHub/문의 링크, 중앙은 제품·문서 링크, 우측은 운영·커뮤니티/상태 링크로 배치한다. 모바일에서는 1열로 쌓고 라이선스는 `details` 접이식으로 유지한다.

## 타일 3–4: 중앙·우측 영역

중앙 열의 레이블은 `사이트`이며, 소개·포트폴리오·문의·Sitemap 순의 짧은 내부 링크 목록이 세로로 정렬되어 있다. 우측 열은 `커뮤니티`이며, 외부 프로젝트/서비스 링크가 외부 이동 아이콘과 함께 배치된다. 두 열 모두 제목은 작고 흐리며, 실제 링크는 더 크고 밝아서 정보 위계가 명확하다.

Cokform에서는 중앙 열을 `서비스`로 두고 폼 만들기·템플릿·보안·FAQ·사이트맵을 배치한다. 우측 열은 `정책·운영`으로 두고 개인정보처리방침·이용약관·오픈소스 고지·서비스 상태·문의로 구성한다. 검증되지 않은 외부 커뮤니티 URL은 넣지 않고, GitHub와 이메일만 실제 URL이 있는 경우에만 외부 이동 표기로 노출한다.

## 로컬 구현 검증

Vite preview에서 `http://localhost:4173/sitemap`이 정상 렌더링되었고, 서비스·정책과 신뢰·XML 사이트맵의 링크 구성이 확인됐다. 홈 화면에서는 새 푸터가 브랜드 설명, GitHub, 서비스 링크, 정책/운영 링크, 접이식 오픈소스 고지, 저작권·개인정보 운영 문구를 모두 노출했다. 데스크톱 기본 렌더링에서 컬럼 구조와 링크 접근성은 정상으로 확인됐다. 다음 검증에서는 실제 Cloudflare Pages 배포 후 `/privacy`, `/terms`, `/sitemap`, `/security`, `/faq`, `/sitemap.xml`의 HTTP 상태와 모바일 뷰를 확인한다.

`/privacy`와 `/terms`도 Vite preview에서 각각 기존 개인정보·법적 안내와 서비스 이용약관 콘텐츠를 정상 렌더링했다. 따라서 고정 URL 라우팅은 로컬 빌드 기준으로 동작한다. 운영 배포 후 Cloudflare Pages의 `_redirects` 규칙이 직접 진입에서도 동일하게 동작하는지 HTTP 및 브라우저 검증이 필요하다.
