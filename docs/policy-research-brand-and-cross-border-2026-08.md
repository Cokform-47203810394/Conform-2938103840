# 브랜드 리소스·국외이전·서비스 이용제한 조사 메모

> 이 문서는 Cokform 공개 정책과 브랜드 리소스 센터를 작성하기 위한 내부 조사 기록입니다. 법률 자문이 아니며, 실제 처리업체·리전·계약 상태가 변하면 공개 문서와 함께 갱신해야 합니다.

## 1. 참고 문서에서 가져올 정보 구조

룩세렛의 브랜드 정책과 서비스 이용제한 문서는 다음 구조를 사용한다.

| 구성 | Cokform 적용 방향 |
|---|---|
| 브랜드 자산·색상·금지 사례 | 실제 로고·마크, 색상, 여백·비율·가독성 기준, 문의 경로를 제공 |
| 저작권·상표 사용 기준 | Cokform 로고·문서·UI를 사칭·변형·오인 유발 용도로 쓰지 않도록 규정 |
| 이용제한 사유 | 보안·불법·피싱·스팸·권리침해·개인정보 오남용·자동화 남용을 구체화 |
| 이용제한 절차 | 원칙적 통지, 긴급 예외, 소명·재검토 경로, 조치 유형을 명시 |
| 국외이전 고지 | 실제 처리자별 데이터 항목·국가·시점·방법·목적·보유기간·거부 효과를 공개 |

Cokform은 원문·표현·표를 복제하지 않고, 자체 제품 흐름에 맞춰 재작성한다.

## 2. 확인된 Cokform 처리 구조

| 처리자 또는 기능 | 확인된 사실 | 공개 고지에서의 처리 |
|---|---|---|
| Supabase | Cokform 프로젝트 `bnbdxcyarerrmijuvxdb`는 `ap-northeast-2` 리전으로 확인됨 | 서울 리전 데이터베이스·인증·암호문 저장으로 명시. 국내 처리로 표시 |
| Cloudflare Pages | 정적 웹 앱 배포와 전송 경로에 사용 | 전 세계 엣지 네트워크에서 요청 기술정보가 처리될 가능성을 조건부 고지. 계약·기능별 데이터 처리 위치는 운영자가 재확인 |
| Google OAuth | 작성자 Google 로그인에 사용 | Google 계정으로 직접 인증되는 기능으로 구분. Cokform이 Google 계정 원문을 수집하는 기능으로 표현하지 않음 |
| Google Drive / Sheets | `drive.file` 범위를 사용해 사용자가 명시적으로 권한을 허용한 경우에만 내보낸 파일을 Drive에 생성 | 선택 기능·사용자 동작 시점의 직접 전송으로 별도 고지. 제공 또는 저장 국가·계정 정책은 Google 서비스 기준 확인 필요 |
| 응답 원문 | 응답자 브라우저에서 폼별 공개키로 암호화되고 저장 | 저장 경로에는 암호문이 보관되며, 복호화는 작성자 브라우저에서 수행된다고 분리 설명 |

## 3. 국외이전 문서에 넣어야 할 공개 항목

개인정보보호위원회 안내에 따르면 개인정보를 국외로 제공·처리위탁·보관할 때 처리방침에 이전 근거와 다음을 고지해야 한다.

1. 이전되는 개인정보 항목
2. 이전 국가, 시기, 방법
3. 이전받는 자의 명칭과 연락처
4. 이전받는 자의 이용 목적과 보유·이용 기간
5. 이전 거부 방법·절차와 거부 효과

Cokform 공개 문서는 **확정된 사실**과 **조건부 외부 연동**을 분리한다. 국가·수탁자·보유기간을 확정하지 못한 항목은 사실인 것처럼 단정하지 않고, 외부 연동을 활성화하기 전에 운영자 검토가 필요하다고 적는다.

## 4. 서비스 이용제한 설계 원칙

이용제한 사유는 다음 범주로 제한한다.

| 범주 | 예시 |
|---|---|
| 법령·권리 침해 | 사기, 피싱, 저작권 침해, 타인 사칭, 명예·프라이버시 침해 |
| 개인정보 오남용 | 수집 근거 없는 개인정보 수집, 민감정보·고유식별정보 부적절 수집, 정보 유출 유도 |
| 보안·서비스 안정성 침해 | 취약점 악용, 자동화 과부하, 접근통제 우회, 악성코드·스크립트 유포 |
| 스팸·기만 행위 | 대량 광고, 악성 리디렉션, 응답자 오인 유도 |
| 정책 반복 위반 | 합리적인 시정 요청 후에도 반복되는 위반 |

조치는 사안의 긴급성·고의성·피해 규모·반복성을 고려하며, 원칙적으로 사전 통지·소명 기회를 제공하되 보안 사고·법령 위반·권리 침해가 긴급한 경우 임시 제한을 먼저 할 수 있게 설계한다.
