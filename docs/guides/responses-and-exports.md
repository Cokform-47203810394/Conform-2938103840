# 응답 운영과 내보내기

Cokform의 응답은 공개 폼에서 제출될 때 암호화되어 저장됩니다. 폼 작성자는 개인키 금고를 열어야 답변을 복호화해 볼 수 있습니다.

## 응답 확인

편집기의 `답변` 탭에서 응답 수, 질문별 요약, 이메일 기록을 확인합니다. 개인키 금고가 잠겨 있으면 답변 원문과 암호화된 버전 기록을 볼 수 없습니다.

> 금고가 잠긴 상태에서도 질문과 운영 설정은 편집할 수 있습니다. 다만 응답·버전 기록은 복구 비밀번호로 금고를 연 뒤에만 읽습니다.

| 확인 항목 | 설명 |
|---|---|
| 질문별 요약 | 객관식·체크박스·드롭다운 등 선택형 답변의 분포를 확인합니다. |
| 자유 입력 답변 | 짧은 답변·장문·날짜·시간의 제출 값을 확인합니다. |
| 기록된 이메일 | 이메일 기록을 켠 폼에서만 별도 카드로 표시됩니다. |
| 응답 수 | 복호화 가능한 응답 수를 표시합니다. |

## 응답 기간 운영

`운영` 탭에서 시작·마감 시각을 설정하거나 즉시 마감·재개할 수 있습니다.

- 시작 시각 전: 응답자는 아직 접수하지 않는다는 안내를 봅니다.
- 마감 시각 후 또는 수동 마감: 공개 폼에서 제출할 수 없습니다.
- 재개: `지금 다시 열기`를 선택하면 공개 응답이 다시 가능합니다.

마감 전에는 공유 링크를 실제 브라우저에서 한 번 열어 응답 가능 상태를 확인하는 것이 좋습니다.

## 내보내기

내보내기는 작성자의 현재 기기에서 복호화한 데이터로 생성됩니다. 원문이 들어갈 수 있는 파일은 안전한 기기에만 저장하고, 공유가 끝난 파일은 조직의 보관 기준에 따라 정리하세요.

| 형식 | 용도 | 포함 기준 |
|---|---|---|
| CSV | 스프레드시트·분석 도구로 가져오기 | 질문 답변과 이메일 기록 설정 시 이메일 열 |
| Excel 호환 파일 | Excel에서 바로 열어 검토 | 질문 답변과 이메일 기록 설정 시 이메일 열 |
| JSON | 개발·백업·시스템 연계 | 구조화된 질문·응답 행 |
| 요약 PNG | 선택형 응답의 비식별 요약 공유 | 자유 입력 원문 미포함 |
| 응답 요약 PPTX | 보고용 요약 자료 | 자유 입력 원문 미포함 |
| Google Sheets / Drive | 현재 Google 계정의 Drive로 파일 생성 | Google 권한 동의가 필요함 |

### 스프레드시트 안전성

응답 값이 `=`, `+`, `-`, `@` 등 수식처럼 해석될 수 있는 문자로 시작하면 내보내기 시 텍스트로 취급합니다. 다운로드한 파일을 다른 사람에게 전달하기 전에는 불필요한 개인정보 열을 제거하세요.

## 전체 응답 삭제

`답변` 탭의 전체 삭제는 암호화된 응답을 삭제하는 되돌릴 수 없는 작업입니다. 다음을 먼저 확인하세요.

1. 보관이 필요한 응답은 필요한 형식으로 내보냈는지 확인합니다.
2. 수집 목적과 보유기간이 끝났는지 확인합니다.
3. 공동 운영자가 있다면 삭제 시점과 근거를 공유합니다.

## 참여 이력

응답자는 자신이 참여한 폼의 제목·문항 수·참여 시각 같은 메타데이터를 기기와 로그인 계정 기준으로 볼 수 있습니다. 답변 원문과 개인키는 참여 이력에 저장하지 않습니다.

폼을 삭제하면 관련 응답과 이 기기의 참여 이력 메타데이터도 함께 정리됩니다.
