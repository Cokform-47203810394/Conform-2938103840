# 폼 만들기와 공유

이 가이드는 Cokform에서 첫 폼을 만들고, 응답 암호화 키를 준비한 뒤 공개 링크로 공유하는 기본 흐름을 설명합니다.

## 시작 전 확인

폼을 만들려면 Google 로그인이 필요합니다. 공개 링크로 응답하는 사람은 로그인하지 않아도 됩니다. 응답 내용을 암호화해 읽으려면, 폼을 처음 만들 때 **개인키 금고**를 설정해야 합니다.

> 복구 비밀번호는 Cokform이 알거나 재설정할 수 없습니다. 다른 서비스와 겹치지 않는 긴 문구를 정하고, 안전한 별도 위치에 보관하세요.

## 1. 시작점 고르기

홈에서 **빈 양식**을 선택하거나 연락처·행사 참석·파티 초대·신청서·동의서 등의 템플릿을 선택합니다. 템플릿은 질문 구조를 빠르게 시작하는 용도이며, 실제 수집 목적과 고지 내용은 운영자가 확인해야 합니다.

| 선택 | 적합한 경우 |
|---|---|
| 빈 양식 | 질문 구성부터 직접 설계할 때 |
| 연락처 정보 | 이름·연락 방법 등 기본 접수 항목이 필요할 때 |
| 행사 참석 여부 | 참석/불참과 추가 선택지를 받을 때 |
| 개인정보 처리 동의서 | 수집 목적·항목·보유기간과 동의 질문을 빠르게 구성할 때 |

## 2. 질문 구성하기

`흐름` 탭에서 질문을 추가하고, 질문 유형과 필수 여부를 설정합니다. 짧은 답변·장문·객관식·체크박스·드롭다운·날짜·시간·선형 배율·개인정보 동의 질문을 조합할 수 있습니다.

질문 제목은 응답자에게 그대로 보이며 내보내기 열 이름에도 사용됩니다. 짧고 명확하게 작성하고, 필수 질문은 꼭 필요한 정보에만 사용하세요.

## 3. 개인키 금고 만들기

`운영` 탭의 **개인키 금고와 복구**에서 `금고 열기`를 선택하고 새 복구 비밀번호를 만듭니다. Cokform은 폼별 공개키와 개인키를 생성합니다. 개인키는 이 브라우저에 암호화된 금고 형태로 저장되고, 응답을 볼 때만 복구 비밀번호로 해제됩니다.

| 항목 | 권장 방식 |
|---|---|
| 복구 비밀번호 | 12자 이상, 다른 서비스와 다른 긴 문구 |
| 키 백업 | 암호화 키 백업 파일을 별도 안전한 위치에 보관 |
| 전체 복구 번들 | 폼·암호문 응답·버전을 함께 보관해야 할 때 별도 생성 |
| 기기 교체 | 새 기기에서 키 백업 또는 전체 복구 번들을 가져온 뒤 금고 열기 |

## 4. 운영 설정 정하기

`운영` 탭에서 필요한 설정만 켭니다.

- **이메일 주소 기록**: 응답자에게 기록 사실을 고지하고 이메일 입력칸을 표시합니다.
- **응답자 사본 요청 허용**: 이메일을 적은 응답자가 사본 요청을 선택할 수 있게 합니다.
- **응답 1회로 제한**: 같은 브라우저의 중복 제출을 줄입니다. 계정 기반의 완전한 본인 인증 제한은 아닙니다.
- **응답 기간과 마감**: 시작·마감 시각을 지정하거나 `지금 마감하기`와 `지금 다시 열기`를 사용합니다.
- **응답 보관기간**: 목적 달성 뒤 파기할 기준일을 설정합니다.

개인정보를 수집할 수 있는 질문이 있다면 **개인정보 수집 안내 표시**와 명시적 동의 질문을 함께 점검하세요. 자세한 기준은 [개인정보 수집 운영](privacy-operations.md)을 참고합니다.

## 5. 미리보기와 공유

편집기 상단의 미리보기로 응답자가 볼 화면을 점검합니다. 모든 질문과 고지, 마감 상태를 확인한 뒤 `공유 시작` 또는 링크 복사로 공개 URL을 전달합니다.

공개 링크를 전달하기 전에는 다음을 확인하세요.

1. 금고와 암호화 키가 준비되었는지 확인합니다.
2. 응답 시작·마감 설정이 맞는지 확인합니다.
3. 이메일 기록과 개인정보 고지가 실제 운영 목적과 맞는지 확인합니다.
4. 응답자에게 연락할 방법과 문의처를 폼 설명에 적습니다.
