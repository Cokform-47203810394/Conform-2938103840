# 문제 해결

Cokform 사용 중 자주 만나는 상황을 먼저 확인하는 가이드입니다. 응답 원문이나 복구 비밀번호를 지원 채널에 보내지 마세요.

## 개인키 금고를 열 수 없어요

| 확인 | 조치 |
|---|---|
| 복구 비밀번호를 정확히 입력했는가 | 공백·대소문자·특수문자를 포함해 다시 확인합니다. |
| 다른 기기에서 사용하는가 | 암호화 키 백업 또는 전체 복구 번들을 가져옵니다. |
| 브라우저 데이터가 초기화됐는가 | 백업 파일이 있으면 금고 가져오기를 사용합니다. |
| 비밀번호와 백업이 모두 없는가 | Cokform은 비밀번호를 재설정하거나 개인키를 복구할 수 없습니다. |

복구 비밀번호를 반복해서 추측하기보다, 백업 파일과 보관 위치를 먼저 확인하세요.

## 응답이 제출되지 않아요

1. 공개 폼이 `응답 받는 중`인지 확인합니다.
2. 응답 시작·마감 시각과 수동 마감 상태를 확인합니다.
3. 필수 질문과 이메일 입력 형식이 맞는지 확인합니다.
4. 같은 브라우저의 응답 1회 제한이 켜져 있는지 확인합니다.
5. 새로고침 후 다시 시도하거나 다른 네트워크에서 확인합니다.

폼 작성자는 편집기 `운영` 탭에서 응답 기간을 즉시 열거나 마감할 수 있습니다.

## 답변 탭이 비어 있거나 잠겨 있어요

답변 탭은 개인키 금고가 잠겨 있으면 복호화되지 않습니다. `운영` 탭에서 금고를 열고 올바른 복구 비밀번호를 입력한 뒤 다시 답변 탭을 확인하세요.

응답 수가 0이면 공개 링크를 직접 열어 테스트 응답을 넣기 전에, 실제 응답이 도착했는지와 폼의 응답 기간 설정을 확인합니다.

## 공개 링크가 열리지 않거나 마감으로 보여요

- 링크에 폼 ID가 끝까지 포함됐는지 확인합니다.
- `운영` 탭에서 수동 마감 상태, 시작 시각, 마감 시각을 확인합니다.
- 링크를 복사한 뒤 메신저의 미리보기 캐시가 남아 있을 수 있으므로 새 브라우저 창에서 열어봅니다.
- 폼을 삭제했다면 공개 링크도 더 이상 사용할 수 없습니다.

## CSV·Excel·JSON 내보내기가 안 보여요

내보내기는 현재 기기의 브라우저가 다운로드를 허용해야 합니다.

1. 개인키 금고를 열어 답변이 보이는 상태인지 확인합니다.
2. 브라우저의 다운로드 차단·팝업·보안 정책을 확인합니다.
3. 다운로드 폴더와 브라우저 다운로드 기록을 확인합니다.
4. 필요한 경우 JSON 또는 다른 형식을 먼저 시도합니다.

Google Sheets·Drive 전송은 현재 Google 계정의 파일 생성 권한 동의가 필요합니다. 권한을 허용한 뒤 원래 폼으로 돌아와 다시 실행하세요.

## 지원 요청 전 준비할 정보

지원 문의에는 다음 정보만 정리하세요.

- 문제가 발생한 기능과 시각
- 폼 제목 또는 공개 URL의 폼 ID
- 화면에 표시된 오류 문구
- 사용 기기·브라우저·네트워크 환경

**복구 비밀번호, 개인키 백업 파일 원문, 응답 원문, 민감한 CSV 파일은 보내지 마세요.**
