# 개인정보 수집 운영

이 문서는 Cokform에서 개인정보가 포함될 수 있는 폼을 운영할 때 필요한 실무 점검 항목을 설명합니다. Cokform의 암호화 기능은 보호 수단이며, 수집 목적과 운영 책임을 대신하지 않습니다.

> 실제 법률 적용과 조직의 의무는 수집 항목·업종·계약 관계·처리 방식에 따라 달라질 수 있습니다. 중요한 운영 전에는 조직의 법무·개인정보 담당자와 검토하세요.

## 수집 전 원칙

개인정보는 **필요한 목적에 필요한 항목만** 받습니다. 이름·연락처·이메일·주소·식별번호처럼 개인을 알아볼 수 있는 정보는 "있으면 편한 정보"가 아니라 운영 목적상 꼭 필요한지 먼저 판단합니다.

| 점검 항목 | 확인할 질문 |
|---|---|
| 수집 목적 | 이 정보가 없으면 어떤 업무를 할 수 없는가? |
| 수집 항목 | 최소 항목만 남겼는가? 선택 항목과 필수 항목을 구분했는가? |
| 보유 기간 | 목적 달성 뒤 언제, 어떤 기준으로 파기하는가? |
| 제3자 제공·위탁 | 외부 전달이나 처리 위탁이 있는가? |
| 응답자 권리 | 거부할 수 있는지, 거부 시 어떤 제한이 있는지 설명했는가? |

## Cokform 설정 흐름

1. `흐름` 탭에서 개인정보가 필요한 질문을 만들고, 필수 여부를 확인합니다.
2. `운영` 탭에서 **개인정보 수집 안내 표시**를 켭니다.
3. 수집 목적·수집 항목·보유 기간을 실제 운영 내용으로 작성합니다.
4. 필요하다면 **개인정보 수집·이용 동의** 질문을 추가합니다.
5. 동의하지 않는 경우 제출이 제한되는지 실제 절차와 맞는지 확인합니다.
6. 응답 보관기간을 목적 달성 뒤 파기 기준에 맞게 설정합니다.

폼 편집기의 개인정보 점검은 질문 제목과 설정을 기준으로 주의가 필요한 지점을 알려줍니다. 이 점검은 보조 도구이며, 법률 자문이나 운영자의 최종 검토를 대체하지 않습니다.

## 이메일 기록

이메일 주소 기록을 켜면 공개 응답 화면에 기록 사실과 이메일 입력칸이 나타납니다. 이메일은 응답과 함께 암호화되어 저장되지만, 수집 필요성과 고지 내용은 운영자가 책임집니다.

| 상황 | 권장 설정 |
|---|---|
| 접수 결과를 직접 안내해야 함 | 이메일 기록을 켜고 이용 목적을 고지 |
| 익명 의견 수집 | 이메일 기록을 끄고 불필요한 식별 질문 제거 |
| 사본 요청을 받을 필요가 있음 | 이메일 기록과 응답자 사본 요청 허용을 함께 검토 |

## 응답 보유·파기

응답 보관기간은 "얼마나 오래 갖고 싶나"가 아니라 "목적 달성 뒤 얼마나 보관해야 하는가"를 기준으로 정합니다. 운영 탭에서 설정한 보관기간이 지나면 응답은 자동 정리 대상이 됩니다.

운영자는 정기적으로 다음을 확인하세요.

- 마감된 폼을 계속 열어둘 필요가 있는지 확인합니다.
- 더 이상 필요 없는 응답은 내보내기 파일까지 포함해 파기합니다.
- 공유했던 CSV·Excel·JSON 파일의 저장 위치와 접근 권한을 검토합니다.
- 개인정보 처리 목적이 바뀌면 기존 고지와 동의가 여전히 맞는지 점검합니다.

## 문의와 정정 요청

폼 설명에는 응답자가 문의·정정·삭제 요청을 할 수 있는 연락 방법을 적는 것이 좋습니다. 플랫폼 일반 문의는 Cokform 안내 페이지의 연락처를 사용하고, 개별 폼의 응답 처리 문의는 해당 폼 운영자가 직접 안내해야 합니다.
