# Cokform 브랜드 리소스

Cokform은 **원하는 대로, 콕 묻고 받아요**라는 슬로건 아래, 자유로운 질문 설계와 개인정보 보호를 함께 제공하는 한국 실무형 폼 도구입니다. 이 문서는 Cokform 브랜드 자산을 일관되고 오인 없이 사용하기 위한 기준입니다.

> 브랜드 자산은 제품·파트너십·언론·커뮤니티 소개 등 Cokform을 정확하게 설명하는 목적에만 사용하세요. 로고를 사용해 Cokform의 공식 제휴·보증·승인이 있는 것처럼 보이게 해서는 안 됩니다.

## 공식 자산

| 자산 | 용도 | 저장소 경로 |
|---|---|---|
| 기본 로고 | 문서, 소개 자료, 밝은 배경의 웹·인쇄물 | [`public/brand/cokform-logo.svg`](../public/brand/cokform-logo.svg) |
| 심볼 마크 | 앱 아이콘, 좁은 영역, 파비콘·프로필 이미지 | [`public/brand/cokform-mark.svg`](../public/brand/cokform-mark.svg) |
| OG 이미지 | 링크 미리보기 | [`public/og-image.png`](../public/og-image.png) |

공식 웹 자산은 [Cokform 리소스 센터](https://cokform.pages.dev/resources)에서 확인할 수 있습니다. 파일은 SVG 원본을 우선 사용하고, 재배포 전 최신 버전인지 확인하세요.

## 다운로드 형식과 해상도

공식 원본은 SVG이며, 크기를 키워도 품질이 떨어지지 않는 벡터 파일입니다. 웹·문서·인쇄 환경을 위해 동일 원본에서 아래 배포용 파일을 생성합니다.

| 자산 | SVG | PNG (투명 배경) | JPG (밝은 배경) | PDF |
|---|---|---|---|---|
| 기본 로고 | 원본 벡터 | 1024px, 2048px, 4096px | 1024px, 2048px, 4096px | 벡터 PDF |
| 심볼 마크 | 원본 벡터 | 512px, 1024px, 2048px | 512px, 1024px, 2048px | 벡터 PDF |

PNG는 투명 배경이 필요한 웹·디자인 작업용이며, JPG는 밝은 배경의 문서나 일반 업로드용입니다. PDF와 SVG는 인쇄물·편집 프로그램에서 벡터 품질을 유지해야 할 때 사용합니다. 모든 래스터 파일에는 300 DPI 메타데이터를 넣습니다.

## 로고 사용 원칙

기본 로고는 심볼과 워드마크가 하나의 비율로 설계되어 있습니다. 가능하면 원본 SVG를 사용하고, 아이콘만 필요한 좁은 영역에서만 공식 심볼 마크를 사용합니다.

| 해야 할 일 | 하지 말아야 할 일 |
|---|---|
| 원본 비율을 유지 | 가로·세로 비율을 임의로 늘리거나 줄이기 |
| 흰색 또는 충분히 밝은 단색 배경 사용 | 가독성이 낮은 사진·패턴 위에 바로 올리기 |
| 로고 주변에 충분한 여백 확보 | 다른 로고·문구·테두리를 로고에 붙이기 |
| 공식 색상과 원본 파일 사용 | 임의 색상, 그림자, 외곽선, 그라데이션 효과 적용 |
| 마크만 사용할 때 공식 마크 파일 사용 | 워드마크 일부만 자르거나 심볼을 새로 그리기 |

## 명칭과 문구

- 첫 표기는 `콕폼(Cokform)` 또는 문맥에 맞는 `콕폼`을 사용합니다.
- 영문 표기는 `Cokform`을 사용합니다. `COKFORM`, `Cok Form`, `Cockform` 등 다른 표기는 공식 서비스명으로 사용하지 않습니다.
- 응답 암호화의 특성은 `작성자만 자신의 키로 응답을 읽도록 설계`라고 표현합니다. 절대적인 보안 보장이나 모든 위험이 제거된다는 표현은 사용하지 않습니다.
- Cokform을 통한 폼 운영의 개인정보 처리 책임은 해당 폼 운영자에게도 있음을 숨기지 않습니다.
