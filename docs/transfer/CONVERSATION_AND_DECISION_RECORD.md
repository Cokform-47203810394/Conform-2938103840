# 대화·결정 이식 기록

**범위:** 이 문서는 원본 채팅의 전체 로그가 아니라, 콕폼의 기능·보안·운영 방향을 바꾼 사용자 요구와 그에 따른 결정·구현 상태를 이식 가능한 형태로 요약한다. 개인키, 실제 응답, OAuth 토큰, 브라우저 세션, 사용자의 개인 대화 원문은 의도적으로 포함하지 않는다.

## 제품의 출발점

사용자는 한국 시장, 특히 행사·교육·커뮤니티·소규모 운영자가 쓸 수 있는 폼을 원했다. 인프라 비용은 월 1만 원 이하를 목표로 했고, Cloudflare Pages와 Supabase 무료 구간을 사용하기로 했다. Google OAuth는 폼 작성자 인증에만 사용하며 공개 응답자는 로그인 없이 제출할 수 있어야 한다.

가장 강한 제품 원칙은 두 가지다. 첫째, 사용자의 자유도를 1순위로 둔다. 둘째, 응답 원문은 누구도 임의로 읽을 수 없도록 E2EE 경계를 유지한다. 이 때문에 키를 잃었을 때 서비스가 비밀번호 재설정으로 응답을 열어 주는 기능은 만들지 않으며, 사용자 소유 복구 파일·기존 기기·복구 번들을 통해서만 복구하게 한다.

## UI·UX에 대한 강한 피드백과 현재 원칙

사용자는 모든 것을 같은 둥근 흰 카드, 같은 그림자, 같은 두께의 테두리로 만드는 AI식 UI를 싫어한다. 따라서 카드 사용은 역할이 있을 때만 허용한다. 템플릿은 작업대, 수치는 정보 행, 참여 이력은 목록, 실제 폼은 콘텐츠 미리보기로 구분한다. 그림자를 덧붙여 해결하려 하지 않는다.

글자도 마찬가지다. 불필요한 semibold·medium·추상 라벨을 줄이고, 본문은 normal, 조작 요소는 medium, 핵심 제목만 bold로 쓴다. 숫자와 카운트는 `font-mono`를 쓰지 않고 Pretendard로 통일했다.

템플릿 가로 행은 잘린 채 정지해 보이면 안 된다. 자동 넘김, 끌기, 이전·다음 제어, 위치 표기로 조작 가능성을 명확히 해야 한다. 다만 자동 움직임은 사용자가 멈출 수 있어야 한다.

## 브랜딩·유입에 대한 결정

콕폼은 Discord 전용 서비스가 아니다. Discord는 파일럿·피드백 채널 하나일 뿐이고, 카카오, 네이버 검색, 당근 지역 파일럿, 파트너 운영자, 자체 가이드와 사례를 분산 채널로 본다. 홈과 OG 이미지도 ‘한국 실무용 폼’, ‘접수부터 마감까지’라는 실제 업무 장면을 말해야 한다.

브랜드의 ‘콕’은 모든 문구에 반복하지 않고 다음 보조 문장으로만 쓴다.

> 필요한 걸 콕 집어 묻고, 운영에 필요한 답만 받으세요.

## 보안·개인정보에 대한 결정

Turnstile은 오탐 때문에 제거됐다. 제출 보호는 일반적 스팸 방어와 정원 제한에는 유효하지만, 브라우저 기반 한 번 제출 제한은 시크릿 모드·새 프로필에서 바뀔 수 있다. 그러므로 채용·투표·경품처럼 한 사람 1회 또는 공정성을 요구하는 용도에는 현 방식으로 보장 문구를 쓰면 안 된다.

컨시어지 테스트에서 콕폼 운영자가 실제 신청자 원문, 이력서, 연락처, 민감정보를 받아서 대신 폼을 만들면 안 된다. 더미 데이터로 폼 구조·설정만 지원하고, 실제 응답은 운영자 자신의 E2EE 폼에서만 처리한다. 채용·의료·금융·미성년자·민감정보 수집은 첫 파일럿에서 제외한다.

## 현재 가장 중요한 미완료 작업

1. GitHub 원격 URL과 인증을 복구하고 로컬의 `4c174fb` 매뉴얼 커밋을 원격에 푸시한다.
2. 테스트 러너를 도입하고 로그인/폼 생성/질문 저장/공개 링크/제출 오류/키 없는 복호화 차단을 자동화한다.
3. 키 백업 저장과 다른 환경 복구를 실제로 시연하는 온보딩을 만든다.
4. 답변·키·이메일을 제외한 행동 이벤트만 측정한다.
5. 실제 원문을 받지 않는 컨시어지 파일럿 3회를 운영하고, 재사용 또는 거절 이유를 기록한다.

## 다음 담당자가 지켜야 할 금지선

- 사용 증거 없는 새 기능을 추가하지 않는다.
- 개인키·복구 비밀번호·키 백업·실제 응답 원문을 요청·저장·로그·분석하지 않는다.
- 배포 성공과 사용자 검증 완료를 같은 상태로 표현하지 않는다.
- 브라우저 1회 제한을 신원 보장으로 표현하지 않는다.
- 법률·보안 표현을 과장하지 않는다.
- Discord에만 의존한 성장 전략을 만들지 않는다.

## 원본 대화 데이터의 한계

현재 이식 패키지는 프로젝트에 필요한 **결정과 실행 맥락**을 담는다. 채팅 플랫폼의 원문 전체와 브라우저 로그인 세션은 자동으로 파일 시스템에 안전하게 이식할 수 없으며, 개인 데이터 노출 위험 때문에 포함하지 않는다. 원문 대화가 별도로 필요하다면 사용자가 해당 플랫폼에서 내보낸 기록을 별도 비공개 저장소에 두고, 이 문서의 타임라인과 함께 참조한다.
