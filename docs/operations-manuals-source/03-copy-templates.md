## 7. 사용자 지원 답변

```md

아래 정보만 알려주시면 원인을 좁히겠습니다.
1. 폼 ID 또는 공개 링크의 앞부분
2. 문제가 난 대략적인 시각
3. 사용한 기기와 브라우저
4. 화면에 보인 오류 문구
5. 개인정보·답변 내용이 가려진 화면

[현재 확인한 사실]
[사용자가 해볼 순서]
[다음 안내 시각]
```
