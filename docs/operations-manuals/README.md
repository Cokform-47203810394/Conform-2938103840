# Cokform 독립 운영 매뉴얼 시스템

이 디렉터리는 콕폼을 혼자서도 운영·개발·보안 관리할 수 있도록 만든 **2,000개 세부 실행 매뉴얼**과 핵심 플레이북이다.

| 구성 | 수량 | 용도 |
|---|---:|---|
| 도메인 | 20개 | 역할과 책임 경계 |
| 업무 흐름 | 도메인당 10개 | 실제 반복 업무 |
| 상황 | 업무 흐름당 10개 | 정기·요청·배포·장애·개인정보 등 맥락 |
| 세부 매뉴얼 | **2,000개** | 하나의 상황에서 바로 실행하는 체크리스트 |

## 먼저 읽을 파일

1. [`00-core-playbooks.md`](./00-core-playbooks.md): 절대 원칙과 금지 사항
2. [`INDEX.csv`](./INDEX.csv): 2,000개 항목 검색·필터용 목록
3. [`DOMAIN-README.md`](./DOMAIN-README.md): 도메인별 책임과 기존 문서 연결
4. 원하는 `manuals/<도메인>/<ID>.md`: 상황별 실행 절차

## 공통 판단 순서

1. 이 일이 사용자 답변·개인키·복구수단을 보게 하는가? 그러면 멈추고 보안·개인정보 매뉴얼을 먼저 연다.
2. 이 일이 새 기능인가? 검증 동결 상태라면 구현하지 않고 가설·성공 기준부터 기록한다.
3. 이 일이 배포·삭제·권한 변경처럼 되돌리기 어려운 일인가? 백업·승인·롤백 기준을 먼저 확인한다.
4. 실행 뒤 무엇을 기록해야 하는가? 매뉴얼의 `기록`과 `완료 조건`을 채운다.

## ID 읽는 법

`COK-GOV-03-07`은 `운영 원칙·의사결정` 도메인의 3번째 업무 흐름, 7번째 상황이다. 모든 파일은 같은 형식이라 검색 도구 없이도 읽을 수 있다.

## 재생성

`python3 scripts/generate_manual_system.py`를 실행하면 이 폴더의 생성 파일을 다시 만들 수 있다. 사람이 직접 수정할 내용은 `00-core-playbooks.md` 또는 프로젝트의 실제 가이드 문서에 기록하고, 생성 파일에는 직접 편집하지 않는다.
