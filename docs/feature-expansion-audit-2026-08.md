# 콕폼 기능 확장 구현 기록

## 2026-08-19 — 알림·첨부 구조 확인

현재 세션의 Resend 연동은 활성화되어 있다. 연동이 제공하는 기능에는 단일 거래성 메일 전송, 도메인 목록·검증, API 키 관리, 자동화 관리가 포함된다. 실제 새 응답 이메일 알림은 제출 Edge Function에서 메일 API를 호출하는 구조가 적합하지만, 발신 도메인 검증·서버 전용 API 키 주입이 완료되기 전에는 사용자에게 실제 발송 기능으로 노출하지 않는다. 2026-08-19 점검에서 현재 Resend 연결 키는 단일 메일 전송 전용 제한 키여서 도메인 검증 상태를 조회할 수 없었다. 따라서 자동 발송을 배포하려면 콕폼 전용 서버 API 키와 검증된 발신 도메인을 별도로 설정해야 한다.

파일 첨부는 E2EE 보장을 위해 별도 비공개 Storage 버킷, 브라우저 단 암호화, 작성자 전용 단기 다운로드 URL이 모두 필요하다. 이 저장소에는 일반 파일을 평문으로 업로드하지 않는다.

## 2026-08-19 — 기능 추가 후 보안 재검증

`form_notifications`와 `form_response_workflow`는 모두 RLS가 활성화되어 있으며, 각각 작성자 전용 읽기·변경 정책만 가진다. `cokform_response_rate_limits`의 “RLS enabled, no policy” 정보성 경고는 익명·인증 역할을 모두 차단하고 서비스 역할 함수만 접근하도록 설계한 의도된 상태다. Supabase의 leaked password protection 경고는 현재 Google OAuth만 사용하는 콕폼의 비밀번호 로그인 기능과 무관하다.
