# 콕폼 브랜드·제품 진단 초안

## 2026-08-16 배포 화면 관찰

홈은 연한 회색/보라 배경, 상단 중앙 검색창, 작은 템플릿 카드와 최근 설문지 카드로 구성된다. 편집기는 상단 고정 툴바와 중앙의 흰색 카드, 보라색 상단선, 질문 번호(Q01), 질문 유형 셀렉트, 필수 스위치, 질문 추가 버튼으로 구성된다.

## Google Forms와 유사하게 느껴지는 지점

1. 상단 도구막대에 질문·응답·설정 탭을 나누고, 편집 영역을 중앙 카드로 배치한 구조가 Google Forms의 편집 경험과 직접적으로 겹친다.
2. 질문 카드의 라디오 옵션, 유형 드롭다운, 필수 토글, 질문 복제·삭제, 하단 질문 추가라는 조합이 Google Forms의 시각 언어와 기능 관습을 그대로 연상시킨다.
3. 보라색 단일 강조색, 연한 보라색 입력 배경, 둥근 카드, 템플릿 갤러리의 스켈레톤 미리보기는 Google Forms와 Material 3 계열 제품의 익숙한 조합으로 보인다.
4. ‘설문지’, ‘질문’, ‘응답’, ‘설정’, ‘게시’ 중심의 제품 어휘가 도구 중심이라 콕폼만의 감정·행동 중심 브랜드가 드러나지 않는다.

## 개선 방향 가설

콕폼은 범용 폼 도구가 아니라 ‘사람의 응답을 더 잘 받게 만드는 설문 경험 도구’로 포지셔닝하는 것이 적합하다. 핵심 개념은 ‘콕 집어 묻고, 콕 집어 이해하는 폼’이며, 시각 언어는 보라색 Material 복제가 아니라 먹색 텍스트 + 콕폼 그린/라임 포인트 + 따뜻한 아이보리 캔버스 + 응답 흐름을 강조하는 집중형 레이아웃으로 전환한다.

## 제품 개선 우선순위

- P0: 홈·편집기·응답 화면의 색상, 타이포그래피, 버튼, 카드, 아이콘을 하나의 콕폼 토큰으로 통일한다.
- P0: 편집기를 ‘질문 카드 편집기’가 아닌 ‘응답 흐름 캔버스’로 보이게 하는 헤더·진행 상태·질문 미리보기 구조를 도입한다.
- P1: 템플릿을 문서 종류가 아니라 목적과 상황(신청 받기, 의견 듣기, 참석 확인, 동의 받기) 중심으로 재분류한다.
- P1: 게시를 ‘공유 시작’으로 바꾸고, 공유 링크·QR·응답 현황을 한 번에 보여주는 결과 패널을 설계한다.
- P1: 빈 상태, 저장 상태, 오류 상태, 응답 완료 상태의 카피를 콕폼 고유 어조로 바꾼다.
- P2: 브랜드 마크와 아이콘 시스템, 마케팅용 템플릿 썸네일 아트 디렉션을 별도 정리한다.

## 2026-08-16 리브랜딩 1차 미리보기

홈 화면에는 아이보리 캔버스, 먹색 타이포, 그린 포인트, 라임 마크, `ASK IT WELL` 서브라인, 목적 중심 헤드라인이 적용되었다. 기존 보라색 중심의 Google Forms 인상은 크게 줄었지만, 템플릿 썸네일이 여전히 문서 스켈레톤 형태이고 편집기 내부의 질문 카드·탭·유형 선택·하단 질문 추가는 Google Forms 관습을 강하게 남긴다.

편집기 1차 판단: 색상은 콕폼으로 이동했지만 제품 모델은 아직 ‘문서 편집기’다. 다음 구현에서는 상단에 콕폼 로고/작업 상태/공유 시작을 명확히 두고, 질문 탭을 ‘흐름’, 응답 탭을 ‘반응’ 또는 ‘답변’으로 재명명하며, 질문 카드에 응답 목적과 미리보기 감각을 추가해야 한다.
