## 운영 홈 화면 관찰

운영 홈은 브랜드 색과 기본 레이아웃은 안정적이지만, 첫 화면에 비슷한 크기·같은 테두리·같은 미니 폼 썸네일을 가진 템플릿 카드가 11개 연속으로 나타난다. 각 카드가 비슷한 정보 밀도와 세 줄짜리 가짜 질문 미리보기를 반복해, 실제 사람이 고른 업무 도구 목록보다 생성형 UI 샘플 모음처럼 보인다.

문구도 `자주 쓰는 업무 양식`, `더 긴 업무 흐름`, `확장 양식`, `개인정보 없이 집계`, `응답 원문은 작성자만 읽도록 설계했습니다`처럼 설명형 문장이 화면마다 반복된다. 기능 설명은 충분하지만 사용자가 지금 무엇을 해야 하는지보다 서비스가 어떤 원칙을 지키는지 말하는 비중이 높다.

## 1차 개선 원칙

1. 첫 화면의 단일 목표를 `새 폼 만들기`와 `기존 폼 이어서 작업`으로 좁힌다.
2. 템플릿은 한 화면에 모든 종류를 진열하지 않고, 빠른 시작 5개와 실제 상황 중심 카테고리로 나눈다.
3. 카드 내부의 가짜 질문 스켈레톤을 줄이고, 질문 수·예상 용도·개인정보 안내 포함 여부처럼 실제 선택 기준을 쓴다.
4. 보안·개인정보 원칙은 매 화면 반복 대신 필요한 순간에만 짧게 보여준다.
5. 자동 생성된 듯한 균일한 카드·라벨·장식보다 최근 작업과 실제 사용 맥락을 우선한다.

## 추가 점검 대상

- 폼 편집기에서 카드·버튼·안내문이 과도하게 동일한 톤으로 반복되는지
- 공개 응답 화면에서 보안·개인정보 고지가 제출 행동을 방해하는지
- 정적 공개 문서의 지나치게 정형화된 카드 배열과 장문 설명
- 모바일에서 가로 템플릿 캐러셀이 실제 빠른 선택보다 시각적 반복으로 느껴지는지

## 작성자 편집기 관찰

편집기에는 상단 아이콘 버튼, `흐름·답변·운영` 탭, 질문 유형 추가 세로 도구막대, 각 질문 카드의 타입 선택·복제·삭제·더보기·필수 토글·조건부 표시 안내가 한 화면에 동시에 있다. 기능은 강하지만 사용자는 질문 하나를 편집하는 중에도 전체 시스템의 모든 가능성을 본다.

각 질문 카드가 `Q01`, 색 테두리, 드래그 핸들, 동일한 드롭다운, 복제/삭제 아이콘, 필수 토글로 반복된다. 섹션·단답형·객관식·개인정보 동의가 모두 비슷한 컨테이너를 쓰므로 질문의 역할 차이가 약하고, 자동 생성된 편집기 블록처럼 보인다. 개인정보 문구의 `실제 업무에 맞게 반드시 확인하고 수정해 주세요` 같은 안전 문구가 편집 화면에 길게 상시 노출되는 것도 템플릿/AI 초안 인상을 강화한다.

### 편집기 개선 후보

- 상단에서 필요한 액션만 먼저 보이고, 나머지 아이콘은 명확한 `더보기`에 묶는다.
- 기본 질문은 제목·설명·필수 여부 중심의 가벼운 카드로 만들고 유형·조건·복제·삭제는 선택했을 때만 보인다.
- 섹션과 개인정보 안내는 일반 질문과 다른 구조로 분리한다.
- 자동 안내 문구는 상시 본문이 아니라 검토 체크리스트 또는 접힌 도움말로 옮긴다.
